# 像素远征 · 肉鸽格斗

基于原 Java 文字格斗游戏（`格斗游戏需求文档.md`）重制的**纯前端单机肉鸽战斗游戏**。零依赖、零构建，原生 HTML + CSS + JS。

## 本地运行

直接双击打开 `index.html` 即可（无需服务器、无需安装依赖）。

> 也可用任意静态服务器：`python -m http.server` 后访问 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 将以下内容推到一个 GitHub 仓库（保留目录结构）：
   ```
   index.html
   css/style.css
   js/data.js
   js/audio.js
   js/game.js
   js/main.js
   ```
2. 仓库 **Settings → Pages → Source** 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`。
3. 保存后等待构建完成，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

无需任何构建步骤，Push 即上线。

## 玩法

- 开局输入昵称、选英雄（剑士 / 贤者 / 守卫 / 刺客，除剑士外随累计胜场解锁），**三选一开局祝福**，有开场剧情对白。
- **地图选路**：共 8 层，每层在 3 个节点中任选其一：
  - ⚔️ 战斗 —— 敌人可为单个、2人组、一群小怪、召唤师、分身魔或两波连战，胜利后三选一奖励
  - 💀 精英 —— 强化敌人，奖励更多金币并必掉遗物
  - ❓ 事件 —— 风险 / 收益抉择（献祭换遗物、赌博、开箱伏击等）
  - 🏕️ 休息（完全恢复生命和法力） / 🏪 商店 / 👑 Boss（第 8 层，Boss 带小弟）
- **敌人意图**：显示每个敌人下一招（⚔️普攻 / 💥重击 / ⚡蓄力 / 🛡️防御 / 💚治疗 / 🌀召唤），据此「防御」减半伤害，形成博弈。
- **多敌人 + 敌人 AI**：同时对抗多个敌人（一群小怪 / 2人组 / Boss 带小弟），召唤师会召小怪、分身魔血量低时会分身、治疗师自愈、自爆怪死时爆炸。
- **群体技能**：部分技能对全体敌人造成伤害（回旋斩 / 烈焰风暴 / 冰霜新星），对付群怪高效。
- **职业专属技能**：每个职业初始带一个特色技能——剑士召唤剑灵、刺客召唤影分身（随从有血量、每回合自动攻击、会被敌人攻击、阵亡后可重新召唤）、贤者冥想回蓝、守卫坚定回血+护盾。
- **遗物系统**：19 种被动遗物与技能叠加成流派（燃烧流、暴击吸血流、荆棘反伤流、低血狂暴流等），含一次性**复活遗物「不死鸟之羽」**。
- **主动道具**：回血 / 回蓝 / 护盾 / 狂暴药水。
- **属性克制**：火克冰、水克火、电克水、光克暗、冰克龙、龙克龙、暗克光/暗；物↔暗互抗、火抗冰、水抗火、冰抗水/冰/光、龙抗火/水/电、电抗电；敌人可无/单/多属性（多属性倍率相乘）。技能按钮**实时计算伤害数字**，克制数字变绿▲、被抵抗变红▼。
- **战利品标注**：奖励/商店卡片标注「技能 / 道具 / 遗物 / 强化 / 回复」，一目了然；奖励三选一保证至少一个恢复类选项。
- **续档**：对局自动存档到 `localStorage`，标题页可「继续游戏」接着上一局。
- **跨局成长**：累计胜场解锁新英雄；最佳进度记录在 `localStorage`。
- 内置 8-bit 合成 BGM 与音效（命中带噪声低频，更"砸实"），可静音。

## 文件结构

```
index.html        页面骨架（各场景）
css/style.css     像素风样式与动画
js/data.js        角色 / 技能 / 敌人 / 道具 / 奖励数据
js/audio.js       Web Audio 合成 BGM 与音效
js/game.js        战斗与肉鸽核心逻辑
js/main.js        UI 渲染与事件绑定
```
